# 方块世界 — Web 版 Minecraft

一个纯浏览器运行的 Minecraft 风格体素游戏。全部代码/资源自包含在本文件夹，
**双击 `index.html` 即可离线游玩**（无需服务器、无需安装任何东西）。

## 运行方式

- **直接玩**：双击 `index.html`（推荐，已内嵌纹理，file:// 协议下可用）
- 或运行 `start.bat` 启动本地服务器后自动打开浏览器（可选，性能相同）

## 操作

| 按键 | 功能 |
|---|---|
| WASD | 移动 |
| 空格 | 跳跃 / 创造模式双击空格切换飞行 |
| Shift | 潜行（防坠落） |
| Ctrl 或 双击 W | 疾跑 |
| 鼠标 | 视角 |
| 左键 | 挖掘（按住，速度按方块硬度） |
| 右键 | 放置方块（按住连续放置） |
| 1-9 / 滚轮 | 选择热栏方块 |
| E | 物品栏（选择要放入热栏的方块） |
| F3 | 调试信息（坐标/FPS/种子） |
| Esc | 暂停菜单 |

## 还原 Minecraft 的实现细节

- **手感参数**（基于 Minecraft Java 1.18，按反馈调校）：
  - 走路 4.317 m/s、疾跑 5.612 m/s、潜行 1.295 m/s
  - 跳跃初速 0.42 格/tick → 跳高 1.13 格（重力/垂直阻尼调大 → 跳跃干脆利落）
  - 终端速度 58 格/s（加速快、落地干脆，无“羽毛”感）、地面阻尼 0.546 / 空中 0.91
  - 碰撞箱 0.6×1.8、眼睛高度 1.62、20 tick/s 固定步长物理 + 渲染插值
  - 自动跨 1 格台阶（整格地形不再频繁“卡住”）、窗口失焦自动清空按键防卡键
- **厚重手感**：视角摆臂晃动（幅度随疾跑加大）、起跳蹬地镜头反馈、
  高处落地镜头下沉 + 落地音效（按落速增强）、脚步音效随脚下方块材质变化
- **挖掘手感**：破坏时间 = 硬度 × 1.5（无合适工具 ×5），泥土 0.75s / 石头 7.5s，
  10 阶段裂纹贴图、每 0.25s 挖掘音
- **建模**：Minecraft 1.18.2 官方 16×16 像素纹理（31 张，含破坏裂纹），
  方块六面独立贴图（草方块顶/侧/底不同）、水半透明（0.875 水面）、树叶镂空、
  高草十字模型、破坏粒子、掉落物实体（可拾取，堆叠上限 64）
  （方块明暗完全由真实光影提供：无旧式固定面明暗、无 AO 暗角）
- **手持方块**：右下角第一人称手持方块，随热栏切换显示对应方块六面贴图，
  走路前后摆臂、疾跑幅度加大、挖掘前伸抖动、放置前推后收
- **世界生成**：种子化确定性噪声（值噪声 fbm）——大陆/丘陵/高山地形、
  四种生物群系（平原/森林/沙漠/雪原）、橡树、海平面湖泊海洋、
  3D 噪声洞穴、按深度分布的矿石（煤/铁/金/钻石/红石）、基岩层
- **环境**：渐变天空穹顶、太阳/月亮/星星、漂浮云层、昼夜循环（4 分钟一天）、
  动态雾、夜晚月光、日落暖色温、半球天光、太阳多层光晕
- **精美光影**（菜单可关）：太阳实时阴影（PCF 软阴影，随玩家移动）、
  Bloom 高光光晕（天空/太阳发光扩散）、ACES 电影色调映射、水面镜面高光（阳光下波光）、
  低环境光+强太阳 → 受光/背光面明暗对比鲜明（暗面立体感来自真实光照）
- **放置**：半透明放置预览（幽灵方块，随准星显示合法位置、非法位置自动隐藏）、
  右键按住连续放置
- **音效**：WebAudio 程序合成（挖掘/破坏/放置/脚步/拾取/落地），无外部音频文件
- **模式**：生存（硬度挖掘 + 掉落物 + 背包计数）/ 创造（秒挖 + 飞行 + 无限方块）

## 技术栈

- Three.js r159（本地 `lib/three.min.js`，UMD 版，无需构建工具）
- 无框架、无依赖、无构建步骤；WebGL2 / WebGL1 均可
- 区块 16×16×128，圆形视距流式加载（默认半径 6），远区块自动卸载
- **性能**：区块生成分片化（每帧 5ms 预算，主线程不卡顿）、
  网格构建按 maxY 跳过空气层、脏区块重建每帧限 1 个、60Hz 掉落物物理
- 纹理：PNG → base64 内嵌（`js/textures_data.js`，file:// 下避免 canvas 污染），
  灰度 tint 模板自动叠加生物群系色（草绿/树叶绿/水蓝）

## 开发

```
node test/run.js      # 逻辑测试（噪声/物理/世界/网格/手感参数，12 项）
node test/browser.js  # 无头浏览器测试（puppeteer-core + 系统 Chrome/Edge）
node tools/gen_textures_data.js   # 替换 assets/textures/*.png 后重新生成内嵌数据
```

纹理文件在 `assets/textures/`（官方 1.18.2 资源，来自 GitHub 镜像
`InventivetalentDev/minecraft-assets` 的 1.18.2 分支）。想换纹理直接替换 PNG
后运行 `node tools/gen_textures_data.js`。

## 已知限制

- 无存档系统（每次会话新世界，可在标题屏输入种子复现）
- 无实体生物、无红石/合成/背包扩展
- 水的流动逻辑简化为静态水体

## 项目结构

```
index.html          入口（页面/菜单/样式）
lib/three.min.js    Three.js r159（UMD）
js/
  noise.js          确定性噪声（hash + 值噪声 + fbm）
  blocks.js         方块定义表（硬度/纹理/音效/掉落）
  textures.js       纹理加载/tint/图集
  textures_data.js  纹理 base64 内嵌（自动生成）
  world.js          区块存储 + 地形生成
  mesher.js         网格化（AO/面剔除/水/十字模型）
  physics.js        AABB 碰撞（分轴/跨步/穿透防护）
  player.js         玩家控制（MC 精确参数）
  interaction.js    射线/挖掘/放置/掉落物/粒子
  environment.js    天空/昼夜/云/光照
  audio.js          WebAudio 合成音效
  ui.js             HUD/菜单/物品栏/F3
  main.js           主循环/区块管理/输入
assets/textures/    官方 PNG 纹理（可替换）
tools/              纹理内嵌生成脚本
test/               逻辑测试 + 无头浏览器测试
```
